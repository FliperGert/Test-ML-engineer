## Задача 1. Рассадка по возрасту

**Условие.** 5 людей разного возраста случайно садятся за круглый стол. Какова вероятность, что они рассядутся по возрастанию или по убыванию возраста?

**Идея.** За круглым столом вращение всей компании на одно место не меняет рассадку (каждый сохраняет тех же соседей слева и справа). Поэтому одну рассадку можно считать "закреплённой", например посадить самого младшего на фиксированное место, а остальных 4 человек расставить на оставшиеся места. Число различных рассадок равно числу круговых перестановок:

```
(5 - 1)! = 4! = 24
```

Подходящих рассадок две:
- по возрастанию (по часовой стрелке от младшего к старшему)
- по убыванию (то же самое, но в обратную сторону)

Для 5 человек эти две рассадки различны, потому что одна получается из другой зеркальным отражением, а не поворотом.

**Вероятность:**

```
P = 2 / 24 = 1/12
```

**Ответ: 1/12.**
